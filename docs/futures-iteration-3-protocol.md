# Futures research, итерация 3: протокол

Записан до прогонов итерации 3. Пороги после просмотра результатов не меняются.

## Гипотеза

FtOiBreakout 4h (F01): пробой канала по направлению EMA 200 продолжается, если открытый интерес за сутки вырос. Набор монет по датам (`--universe pit`), комиссия тейкера, плечо 1.

## Сетка

- Длина канала: 24, 48, 96 баров. Выход по каналу вдвое короче.
- Порог роста OI за сутки: 0 (контроль, фильтра нет), 3%, 5%, 8%.

12 вариантов. При таком числе проверок лучший вариант завышен, поэтому отбор требует ещё и устойчивости.

## Проверка фильтра OI

Для каждой длины канала сравниваются варианты с порогом и контроль. Если фильтр не улучшает доходность и profit factor ни при одной длине, гипотеза об OI отвергается.

## Отбор в validation

Вариант проходит, если на development:

1. Не меньше 150 сделок.
2. Доходность больше нуля, profit factor не ниже 1,10.
3. Плюс в половине торгуемых монет или больше.
4. Три лучшие сделки дают меньше половины прибыли.
5. Соседние пороги OI при той же длине канала тоже дают доходность больше нуля.

Из прошедших берётся один вариант с наибольшим profit factor.

## Validation и holdout

Вариант проходит validation, если с комиссией тейкера доходность больше нуля и profit factor выше 1,0, а со стрессовой комиссией 0,1% доходность не ниже −5%. Тогда holdout запускается один раз, с комиссией тейкера и стрессовой, и результат публикуется в любом случае. Бумажный портфель получает метку UNVALIDATED.

Если ни один вариант не проходит отбор, гипотеза закрывается, validation и holdout для неё не запускаются.
