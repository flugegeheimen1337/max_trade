# Оператор на домашнем ПК

Лаборатория управляется с того компьютера, где стоит Docker. Облачная сборка только готовит репозиторий. Она не подключается к ПК в Дубае и не качает свечи с домашнего IP.

## Что поставить

1. Docker Desktop для Windows 11, движок WSL2.
2. Дистрибутив Ubuntu в WSL2. Внутри него нужен `python3` (в Ubuntu 24.04 это 3.12).
3. Файл `%UserProfile%\.wslconfig`:

```
[wsl2]
memory=16GB
processors=8
```

После правки выполни `wsl --shutdown` и открой Ubuntu снова.

На время `download` и `verify` в Windows выключи сон и гибернацию. Часы Windows должны быть синхронизированы.

## Первый запуск

В Ubuntu:

```bash
sudo apt update
sudo apt install -y python3 git
git clone https://github.com/flugegeheimen1337/max_trade.git
cd max_trade
git checkout cursor/stage1-freqtrade-lab-a482
./scripts/lab.sh init
```

`init` создаёт `.env` рядом с проектом и локальные пароли API. Это не ключи биржи. Если публичный Binance с домашнего адреса не открывается, в `.env` поставь `EXCHANGE=okx` или `EXCHANGE=bybit` и повтори `init` не нужно: файл уже есть, достаточно поправить строку.

```bash
./scripts/lab.sh doctor
./scripts/lab.sh download
./scripts/lab.sh verify
```

`download` запрашивает BTC/USDT и ETH/USDT, таймфреймы 15m, 1h, 4h и 1d, с 1 января 2020 до последней доступной свечи. Это длинная загрузка. Повторный запуск докачивает дыры, которые биржа ещё отдаёт, и не придумывает свечи.

`verify` дважды гоняет окно `20240101-20240301` со ставкой комиссии 0,1% на сторону и пишет `user_data/reproducibility.json`. Смотри поле `matched`. Число сделок в этом файле — размер прогона, не результат заработка. Пока `matched` не стало `true`, dry-run не запускай.

## Dry-run

```bash
./scripts/lab.sh up
./scripts/lab.sh start
```

`up` поднимает контейнер в состоянии stopped: процесс жив, новые виртуальные сделки не открываются. `start` включает цикл. `pause` запрещает новые входы и оставляет уже открытые виртуальные позиции на их собственных правилах выхода. `stop` останавливает цикл. `down` удаляет контейнер. База `user_data/tradesv3.dryrun.sqlite` остаётся на диске.

FreqUI открывай только локально: `http://127.0.0.1:8080`. Пароль лежит в `.env` в строке `API_PASSWORD`.

## Как этим управляет агент Cursor

Открой клонированный каталог в Cursor на этом ПК. Локальный агент вызывает те же команды `./scripts/lab.sh ...`. Отдельный скрытый процесс ставить не нужно: оператор и есть управляющая программа, а агент только запускает её в WSL.

Ключи биржи агенту не передавай. Для этой сборки они не используются.
