# Crypto Trading Lab

Переносимая первая сборка исследовательской лаборатории. На домашнем ПК она скачивает реальные свечи, прогоняет одну базовую spot-стратегию через Freqtrade и проверяет, что второй бэктест совпал с первым.

Эта сборка не торгует реальными деньгами. Конфиг с `dry_run=false`, фьючерсами, плечом или ключами биржи не запускается.

## Что уже есть

- Образ `freqtradeorg/freqtrade:2026.10`. Оператор на ПК запускается своим Python 3.12, движок живёт внутри образа.
- Spot, пары BTC/USDT и ETH/USDT, рабочий таймфрейм 15m.
- Виртуальный депозит 1000 USDT, ставка пробного прогона 100 USDT, максимум 2 позиции.
- Биржа по умолчанию Bybit. Запасная — OKX, строка `EXCHANGE=okx`. Binance остаётся только запасным источником публичных свечей.
- Локальный оператор `scripts/lab.sh`: скачивание, проверка свечей, бэктест, повторный прогон, запуск и остановка dry-run.
- API и FreqUI только на `127.0.0.1`.

Дополнительно скачиваются таймфреймы 1h, 4h и 1d. Базовая стратегия их не читает: они лежат для следующего этапа.

## Как устроена проверка

Исторические свечи нужны, чтобы проверить гипотезу на прошлом, а не чтобы подогнать прибыльный бот. В этой сборке одна гипотеза: лонг после удержания цены над EMA 200, при EMA 20 выше EMA 50, ADX выше 20, RSI между 45 и 65 и объёме выше среднего. Выход при потере этой структуры или при стопе 8%. Это проба движка. Пять исследовательских схем описаны ниже и в этой сборке ещё не реализованы.

Комиссия в прогоне задана явно: 0,1% на вход и 0,1% на выход. Стакан и спред бэктестер на истории не видит. Окно воспроизводимости по умолчанию: с 1 января по 1 марта 2024. Полная загрузка запрашивает данные с 1 января 2020. Если биржа отдаст более короткий ряд, в отчёте останется фактический диапазон.

Совпадение двух прогонов означает, что движок повторил сам себя. Оно не означает, что стратегия зарабатывает.

## Схемы, которые пойдут следующими

| Схема | Идея | Когда её вообще имеет смысл смотреть |
| --- | --- | --- |
| Trend Following | Продолжение уже подтверждённого восходящего тренда после отката | Спокойный или умеренный рост |
| Mean Reversion | Возврат к среднему в боковике | Нет выраженного падения |
| Breakout | Пробой диапазона после сжатия волатильности | Выход из узкого диапазона |
| Momentum | Импульс, подтверждённый объёмом и старшим таймфреймом | Устойчивое движение, не один рывок |
| Adaptive | Выбор одной из логик по режиму рынка; в падении новые покупки закрыты | После того как четыре простые схемы проверены отдельно |

Пока движок на ПК не повторил один и тот же бэктест, эти схемы не подключаются.

## Перенос на ПК

Нужны Docker Desktop, WSL2 и Ubuntu. Память WSL лучше выставить в 16 ГБ из 32. Сон Windows на время длинной загрузки отключается. Пошаговый сценарий: [docs/PC_OPERATOR.md](docs/PC_OPERATOR.md).

```bash
git clone https://github.com/flugegeheimen1337/max_trade.git
cd max_trade
git fetch origin cursor/stage1-freqtrade-lab-a482
git checkout cursor/stage1-freqtrade-lab-a482
./scripts/lab.sh init
./scripts/lab.sh doctor
./scripts/lab.sh download
./scripts/lab.sh verify
```

`init` сам создаёт `.env` с локальным паролем API и пустыми ключами биржи. Файл не коммитится. Биржа в нём уже `bybit`. Если публичные свечи Bybit недоступны, до `download` поставь `EXCHANGE=okx`.

Дальше, когда проверка повторяемости записана:

```bash
./scripts/lab.sh up      # контейнер поднят, сделки не открывает
./scripts/lab.sh start   # начать виртуальный dry-run
./scripts/lab.sh pause   # не открывать новые, текущие вести по их правилам
./scripts/lab.sh stop    # остановить цикл
./scripts/lab.sh down    # убрать контейнер
```

FreqUI: `http://127.0.0.1:8080`. Логин лежит в `.env`.

Из PowerShell доступен `scripts\lab.ps1`, если установлен Python 3.12. Основной путь для этой машины — Ubuntu внутри WSL2.

## Проверки без биржи

```bash
python3 -m pip install -r requirements-dev.txt
python3 -m pytest
```

Эти тесты проверяют блокировку live-режима, качество ряда и сравнение двух отчётов. Они не скачивают рынок и не измеряют доходность.
